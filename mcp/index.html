MCP Wrapper Pack

Expose MachineSignal as tools for CRMs, AI agents and automated workflows.

MachineSignal currently provides a local stdio MCP-style adapter and a public tool manifest. A buyer machine can read the pack, start the adapter, create a sandbox key and test scoring, orders and payment-test reconciliation without human sales contact.

What This Gives A Machine

Tool discovery

The machine reads a public tool manifest and sees exact callable tool names, inputs, auth rules and guardrails.

Sandbox execution

The machine creates a limited sandbox customer, tests lead scoring and retrieves orders without a human email flow.

Payment safety

The machine can create and reconcile test-mode payment intents while real payment and fiscal invoice remain blocked.

Machine Installation Flow

Step Machine action Call
1 Read the MCP wrapper pack. GET /mcp/machinesignal-mcp-wrapper.json
2 Read the tool manifest. GET /mcp-tool-manifest.json
3 Clone and start the local adapter. python mcp_adapter/machinesignal_mcp_server.py
4 Validate without consuming credits. python mcp_adapter/validate_machine_client_installation_20260603.py
5 Run the sandbox buyer-machine test. python mcp_adapter/machine_buyer_agent_runner_20260603.py

Guardrails

Real payment, fiscal invoice and external contact are not executed in beta. The wrapper is designed for machine evaluation, CRM integration and controlled sandbox testing. Humans supervise and approve irreversible publication or live payment activation.
