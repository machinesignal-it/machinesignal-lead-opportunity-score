# MachineSignal - Owner Paid Beta Activation Checklist

Date: 2026-06-17
Status: final approval gate draft

## Purpose

This checklist is the final owner gate before activating any paid beta.

It does not approve paid beta.

It does not activate payments, invoices, production API keys, real customer data, personal data, external outreach, public marketplace publication, hosted MCP or MCP registry submission.

## Current Decision

Technical sandbox: ready for current scope.

Paid beta preparation: allowed.

Paid beta activation: no-go.

Commercial go-live: no-go.

Reason: owner, fiscal, legal, payment, data, support and cost approvals are not complete.

## Activation Rule

Paid beta can be activated only if every critical item below is explicitly approved.

If one critical item is missing, the decision remains: do not activate.

## Minimum Safe Beta Configuration

If the owner later approves activation, the recommended first configuration is:

- private controlled beta only;
- manual approval for every beta customer;
- sandbox-first integration test;
- production key issued manually only;
- low customer cap;
- low credit cap;
- no personal data;
- no external outreach;
- no public marketplace;
- no hosted public MCP;
- kill switch enabled;
- daily cost cap enabled;
- support escalation capped.

## Explicit No-Go Conditions

Do not activate paid beta if any of these is true:

- fiscal/admin path is unclear;
- payment provider is live but not approved;
- invoice process is unclear;
- terms/privacy/data policy is not approved;
- production keys are not governed;
- customer data rules are unclear;
- cost caps are missing;
- kill switch owner is missing;
- support process is unclear;
- public marketplace or MCP publication is being considered without explicit approval.
