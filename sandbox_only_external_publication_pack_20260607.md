# MachineSignal Sandbox-Only External Publication Pack

Generated: 2026-06-07

Status: sandbox-only publication preparation allowed.

This pack tells MachineSignal agents what can be prepared for external discovery and what remains blocked. The operating rule is simple: publish evidence and importable sandbox materials, but do not create real monetization, real customer commitments, external outreach or irreversible public marketplace publication without owner approval.

## Purpose

MachineSignal is being tested as a machine-first API business. The intended first buyer or evaluator is not a human browsing a landing page, but a CRM, AI agent, RevOps workflow, API directory, Postman workspace, marketplace scanner or MCP-style tool client.

The current objective is to make the product discoverable, importable and testable in sandbox mode by those machines. This is not yet a live commercial launch.

## What Remains Blocked

Agents must not perform these actions without explicit owner approval and legal/fiscal readiness:

- activate live payments;
- publish real payment checkout links;
- create paid marketplace plans;
- publish real API keys or admin keys;
- issue invoices, receipts or fiscal documents;
- promise refunds, SLAs or legal terms not yet approved;
- publish an external marketplace listing irreversibly;
- send emails or outreach to human prospects;
- contact external target companies;
- sign terms, contracts or partner commitments;
- make legal, tax or accounting declarations.

## Required Checks Before Any External Public Publication

Before a Postman public workspace, API directory submission, RapidAPI-style listing or MCP/tool registry listing can move from draft to public, agents must verify:

1. Distribution Readiness Monitor returns OK.
2. Secret scan returns OK.
3. OpenAPI, Postman collection, MCP manifest, `llms.txt`, product catalog and machine onboarding links are reachable.
4. Machine Buyer Evidence Brief is linked.
5. Bounded Private Beta Runner evidence is linked.
6. The listing clearly says sandbox-only or beta where relevant.
7. No live payment, real invoice or external contact is claimed.
8. No real customer API key, admin key, FTP credential, Postman token or Cloudflare token is present.
9. Owner approval is recorded before public external publication.
