A direct sandbox entry point for CRMs, AI agents and automated workflows.

Use this page when Postman UI is unavailable or when a machine needs a canonical route to import, test and evaluate MachineSignal without human sales contact.

What this test entry point is for

For machines

CRMs, agents and workflows can read public JSON, create a limited sandbox key and run the API flow.

For MCP-style clients

Agents can read the wrapper pack and expose MachineSignal as tools through the local stdio adapter.

For sandbox evaluation

The flow tests score, beta deliverables, payment-test sandbox intent and reconciliation.

For controlled publication

This is the public fallback while external Postman workspace publication is blocked by OAuth.

Machine test flow

Step Call or asset Purpose
1 GET machine-api-sandbox-test.json Read this machine-readable test contract.
2 GET machinesignal-mcp-wrapper.json Read MCP-style adapter metadata and expected tools.
3 GET postman_public_collection.json Import request examples without exposing real keys.
4 GET openapi.json Inspect the canonical API schema.
5 POST /v1/sandbox/customers Create a limited sandbox key when the daily anti-abuse limit allows it.
6 POST /v1/lead-opportunity-score Score a domain and receive decision, confidence and next purchase signal.
7 POST /v1/purchase-intent Request Deep Analysis or Action Pack beta deliverables.
8 POST /v1/payment-test/intents Simulate checkout in sandbox mode only.
9 GET /v1/payment-test/reconciliation/{payment_test_id} Confirm no real payment, no external contact and no fiscal invoice.
