Commercial Meaning

The beta supports three machine-side commercial events: score consumption, Deep Analysis purchase and gated Action Pack purchase. The Action Pack is not sold as a generic extra. It is available only when a previous Deep Analysis order exists for the same domain.

This protects the buyer machine from unnecessary downstream spend and makes the product more credible for CRM, RevOps and AI-agent workflows.
