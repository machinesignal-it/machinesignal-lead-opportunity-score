What the machine can test

The sandbox is for low-volume technical evaluation. It does not charge money, does not issue a fiscal invoice and does not contact external targets.

Sandbox limits

  • 5 valid lead opportunity scores.
  • 1 Target Discovery order intent.
  • 1 Deep Analysis order intent.
  • 1 Action Pack order intent.
  • Test/sandbox payment intent only.

Machine buying flow

Step Call Machine purpose
1 GET /llms.txt Discover MachineSignal and machine-readable entry points.
2 POST /v1/sandbox/customers Create a limited sandbox API key without human sales contact.
3 GET /v1/onboarding Read customer state, credits, payment-test mode and available calls.
4 POST /v1/purchase-intent Request Target Discovery when the machine has no starting list.
5 POST /v1/lead-opportunity-score Score a domain and receive a decision such as watchlist, nurture or buy Deep Analysis.
6 POST /v1/purchase-intent Buy Deep Analysis or Action Pack in beta mode when the score justifies it.
7 POST /v1/payment-test/intents Simulate checkout in test or sandbox mode only.
8 GET /v1/payment-test/reconciliation/{payment_test_id} Verify credits, duplicate webhook handling and no real payment execution.
