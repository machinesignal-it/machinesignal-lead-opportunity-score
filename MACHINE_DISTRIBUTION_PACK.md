## Submission message

MachineSignal is a machine-first lead opportunity scoring API for CRM systems, RevOps workflows and AI agents. It exposes OpenAPI, llms.txt, product catalog, machine onboarding and a public sandbox key flow. A machine can create a limited sandbox key, score domains, test Deep Analysis and test Action Pack without human sales contact. The beta does not execute real payments or external outreach.
