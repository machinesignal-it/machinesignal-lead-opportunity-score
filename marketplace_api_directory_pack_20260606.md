## One-line listing

Machine-readable lead opportunity scoring and spend-control API for CRMs, AI agents, RevOps workflows and software platforms.

## What MachineSignal sells

MachineSignal does not sell a human consultancy conversation as the main product. It sells structured API outputs that a customer machine can read, store and act on:

- target discovery when the customer machine has no list;
- scoring when the customer machine has domains or companies to prioritize;
- Deep Analysis when a score needs evidence before more budget is spent;
- Action Pack when Deep Analysis confirms that a CRM or workflow action should be prepared;
- recurring feeds and API plans for ongoing use.

## Why a machine would buy it

A customer machine usually has one of four jobs:

1. Find targets for a declared commercial objective.
2. Prioritize a list before spending enrichment, campaign, CRM or agent budget.
3. Decide whether one promising domain deserves deeper analysis.
4. Produce a CRM-ready or workflow-ready payload after the opportunity is confirmed.

MachineSignal is designed to answer those jobs in JSON, with stop rules and credit tracking.

## Marketplace-ready short description

MachineSignal helps automated systems decide which business domains deserve more sales, CRM or enrichment budget. It returns score, confidence, decision, spend policy, recommended next purchase and machine-readable deliverables such as Deep Analysis and Action Pack.

## Marketplace-ready long description

MachineSignal is a machine-first sales intelligence API for CRMs, AI agents, RevOps workflows and software platforms. The API lets a customer machine create a limited sandbox key, read a product catalog, score domains, request Target Discovery when it has no list, buy Deep Analysis only when a score justifies it, and buy Action Pack only after Deep Analysis confirms the gates.

The product is built around budget control. Invalid, duplicate or non-analyzable records do not consume credits. Deep Analysis acts as the intermediate spend-control layer between a cheap score and a more expensive CRM/workflow action. Action Pack does not send email by itself; it returns CRM-ready JSON, workflow payloads, webhook policy, approval gates and stop rules for the customer system.

Beta mode is sandbox-first. Real payments, fiscal invoices and external target contact are blocked until the owner approves production readiness, legal/fiscal setup and payment terms.

## Machine buying rules

- If the customer machine has no list, start with Target Discovery.
- If the customer machine has domains, start with Score Pack.
- If the score recommends controlled spend, buy Deep Analysis.
- If Deep Analysis confirms all gates, buy Action Pack.
- If evidence is weak, incomplete or non-compliant, stop or keep the lead in watchlist.
- Reuse `Idempotency-Key` for every credit-consuming request.
- Do not execute real payment during beta.
- Do not contact external targets during beta.
