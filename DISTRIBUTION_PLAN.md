# Distribution Plan

Status: private technical beta.

Goal: make MachineSignal discoverable by API consumers, CRM workflows, RevOps automations and AI agents.

## Live Assets

- Website: https://machinesignal.it/
- API overview: https://machinesignal.it/api/
- Beta access: https://machinesignal.it/beta/
- Full OpenAPI: https://machinesignal.it/openapi.json
- LLM discovery: https://machinesignal.it/llms.txt
- Postman collection: https://machinesignal.it/postman_collection.json

## Priority

1. GitHub repository and website as public technical trust layer.
2. Postman Public Workspace as first API discovery/testing channel.
3. RapidAPI provider draft, public only when the endpoint is callable.
4. MCP wrapper and Smithery/MCP directories after the API has a real callable tool.

## Positioning

Machine-readable lead opportunity scoring for CRM, RevOps and AI-agent workflows.

MachineSignal does not sell lead lists and does not run outreach automation. Public examples are synthetic. API access requires beta approval.
