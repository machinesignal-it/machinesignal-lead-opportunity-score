A machine buyer or API evaluator can fetch this URL and import the collection into a private workspace:

https://go.postman.co/import?url=https%3A%2F%2Fmachinesignal.it%2Fpostman_public_collection.json
  • Keep the workspace private until owner approval.
  • Use the environment template for private values only.
  • Run the secret scan checklist before any public publication.
  • Do not execute live payment or external outreach flows during sandbox evaluation.
